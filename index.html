输入、输出与频率的落地规范

这一节把对比表里的“预测穿门交点、候选航迹净空、置信度”拆成可实现的接口。原则是：新增维度必须匹配当前动作权限；预测以观测进入 actor；训练和部署共用同一套前推与检查。

输出：残差，不是重训整个策略

一次决策　v_cmd = check(v_joint + Δv)；首版 Δv = [0, 0, Δv_z]，后续 Δv = [Δv_x, Δv_y, Δv_z]。

PPO 动作维度不等于执行维度：首版 PPO 动作 1 维，执行 3 维；完全版 PPO 动作 3 维，执行 3 维。joint 的占位项不是第 4 维，它只是加在 3 维速度均值上的 detach 偏置。首版残差界参考现有高度探针的 0.8 m/s；先和固定高度探针、几何门中心控制器对照，再判断 PPO 是否必要。

可行性检查有一个 PPO 细节：PPO 用采样到的 Δv 算概率，仿真用 check 后的速度生成状态。硬裁剪会让采样动作和执行动作不一致。首轮只记录风险、不裁剪；确认高度修正站住后，再把 check 加进训练，并记录干预频率。

层频率说明
策略 / base10 HzHITSZ 配方；首版不改

提策略频率会换一个学习问题：同模拟时长样本量 ×2（20 Hz）或 ×5（50 Hz）；gamma 要从 0.99 调到 0.995/0.998；rollout 长度、奖励尺度、动作噪声都要重调。20 Hz base 可作为消融；50 Hz base 不是首跑。先提内环和残差，最后才动策略频率。

加什么

未来穿门点：t_gate、z_cross、边界余量。候选后果：4 候选 × 净空/冲突时间/门余量。观测质量：年龄、未知比例、置信度。

不加什么

原始 256 格占位、每门 4 角点、再下一门、门 ID、绝对 GPS、完整旋转矩阵、上一动作、四条边余量全给、完整协方差。

怎么接

独立 observation group；新增投影零初始化；加载 joint 权重 strict=False；第 0 步输出与 joint 一致；不要用 --resume，recipe 变了会报错。

提案如何接入现有训练

先统一过门事件，再给 PPO 可操作的预测量

三门训练和三门评测共享门平面相交、门洞和门序判定。当前窗口外穿越在训练会推进内部门索引并清连续计数，在三门评测会结束该局。建议把这项口径对齐做独立对照，同时记录相同的门平面交点。整段任务可保留回门重试，由成功触发来推进正式门序。训练代码评测代码

门状态

以门平面为基准，A 阶段只给到门时间、预计垂直偏差和下沿余量；B 阶段再加横向偏差与侧边余量。再下一门/转向、观测年龄和不确定度作为独立消融，不默认塞进 A。门或地标在官方画面里可见时，用视觉纠正姿态与门位。

障碍状态

用相同时间戳查询车辆未来占位和候选机体位置。B 阶段给 4 个候选 × 净空/冲突时间/门余量；原始 256 格占位不进 actor。静态细线用单独的检测、碰撞与压力场景覆盖。

控制边界

从冻结的 joint 得到名义速度，零初始化修正头。首版垂向 |Δv_z| ≤ 0.8 m/s，后续三轴有界；PPO 动作维度不等于执行维度。部署与训练共用同一前推和检查，首轮检查只记录风险，并记录干预频率。

一次决策　v_cmd = 检查(v_joint + Δv)　每条候选同时查两个值 预计穿门余量 和 预测时空净空。

前推首先可用常速度验证数据接口，之后接入现有速度 PI 的响应、延迟和加速度限制。首版固定 10 Hz base，残差/内环先到 50 Hz；20 Hz base 只作为消融。用候选路径上的风险决定何时减速或横移。等待前检查停车点是否会落进车辆路线。进入工厂后由任务状态机切换到定位、搜索和读表流程。比赛接口

训练时同时记录策略提议和实际执行的速度。PPO 用所采样的修正量计算动作概率，仿真用可行性检查后的指令生成下一个状态和奖励；硬检查会让采样动作和执行动作不一致，所以首轮只记录风险，确认高度修正站住后再加入裁剪。以上为设计参数。

B　提前避障37 维 vs 23 维。保持 A 的最佳权重与控制器，对比仅过门修正和加入 4 候选航迹风险；先冻结 base，再释放沿程和横向；残差可到 50 Hz。飞行中碰撞、最小净空、有可行候选的比例；按固定障碍、车辆、细线分组。起点接触单列。
C　赛事观测40 维 vs 37 维。先用 HITSZ 真值做诊断，再以官方 ROS 记录标定的估计误差、延迟、丢帧训练 actor；训练 critic 可读取真值。比较真值、估计输入、估计输入加延迟下的配对结果；在官方模拟器核对门数、时钟和控制模式；检查年龄/置信度校准。

频率不是首轮变量。先固定 10 Hz base + 50 Hz 内环/残差；A/B 站住后再做 20 Hz base 消融。频率消融要对齐模拟时长，而不是只对齐环境步数；提频还要同步调 gamma、rollout、奖励尺度和动作噪声。

短训探针建议每个学习方案 50–100 个更新。按 4,096×20 配方约 410 万–819 万环境步。固定场景哈希、底层控制与有效采样预算，保留新的门组和随机种子做最终检验。主指标按官方优先级报告有效门数，同门数再看时间。训练配方规则
