## 研究问题

绕开一个障碍时，将后续转弯和有序过门纳入候选选择，能否提高连续得分？实验在水平面上模拟定高飞行。判定是逐步运动、碰撞检测和按序过门，网络从随机权重开始。场景、候选、标签和权重均独立于 HITSZ。

## 设计与口径

- 每个初始场景有 5 个横向目标和 2 个速度比例，共 10 个候选。选定后跟踪到沿程 14 m，再用全部方法共享的控制器续飞。每个候选的碰撞、短程通过、通过门数和完赛用时都从仿真中计算。
- 运动模型为水平面有限加速度质点，固定高度，步长 50 ms，限加速度 8 m/s²。障碍建模为横向匀速运动的圆盘，碰撞检查覆盖整个时间步。三个虚拟门按沿程顺序判定。各范围是研究假设。
- 训练、开发、留出分别有 800、200、400 个独立几何族。每族产生 4 局，成对翻转障碍与路线，成员共享基础几何。开发与留出是同分布的新几何。留出集 1,600 局、16,000 条候选结果。额外复核另用 400 个全新几何族。
- 输入使用场景参数给出的准确障碍位置、速度、半径、自身速度与前方弯道几何。D 组去除弯向。控制器的路线跟踪在所有组中相同，所以 D 衡量的是**候选选择时**缺失弯向的影响。
- B 学短程存活和最近净空，C 在相同网络上增加三个有序过门标签；D 与 C 用同样标签。各网络按 3 个随机种子独立训练，最多 32 轮，都以开发集三门完成数选择轮次。表中学习方法为三个随机种子的算术平均。
- 上限逐场读完所有候选的仿真结果再选。配对置信区间以几何族为重采样单位，保持镜像和反向弯的关联。区间反映固定训练种子条件下的场景抽样变动。

## 实测结果

在 1,600 个留出场景中，局部净空规则 A 完成 45.50%，短程训练 B 完成 52.44%，后续进度训练 C 完成 96.79%，遮住弯向的 D 完成 51.31%。当前候选上限为 97.00%。若完全看不到弯向，同一对反向弯场景只能选同一个动作，这个限制下的事后最优完成率是 54.25%。在可行场景中，C 选到能完成三门的候选占 99.79%。

额外复核将 3 份 C 权重冻结，并加入能看到相同弯向的手写规则。它用预估净空与第二道门前可达到的横向位移选候选。在另 1,600 个场景中，这条规则完成 91.25%，C 完成 97.00%。差 5.75 个百分点，按几何族计算的配对 95% bootstrap 区间为 4.25 至 7.38 个百分点。这是与当前这条几何规则的差距，更强的规划器仍可作为对照。

留出集第 0 个几何族的前两局共享初始速度和障碍，只翻转后续弯向。C 的种子 7 模型分别选 +3.6 m 和 −3.6 m 横向目标，速度比例均为 0.72，各过三门。将这两个选择交换，只能各过一门。可在 holdout-choices.csv 的前两行和 holdout-branches.npz 的 gates 数组中复核。

## 适用范围与下一轮

本次为合成赛段的单次候选决策，续飞使用共享控制器。三门完成率衡量该任务；限高、姿态动力学、真实雷达、状态估计误差、反复重规划、官方裁判和实机飞行均待独立验证。当前场景专门让相反弯向影响最优选择，方向消融的大幅下降只代表这类题。

下一轮优先冻结 C 和方向规则，从同一批仿真轨迹生成带时间戳的有噪观测，从点云估计障碍位置和速度，对两者施加相同误差。分开报告理想输入、估计输入、估计输入加延迟下的成对胜负，再判断是否值得扩网络。
